# Repository-native harness for pytest-Jira-xray-plus

Implement the requested harness-engineering practices from the WalkingLabs course,
using the verified Ego City harness only as a reference. Preserve this Python
plugin, stable 0.1.3, Generic targeting, runtime behavior and publishing safeguards.
This is one focused repository-tooling task; gcard-game is a separate later task.

## Acceptance criteria

- A concise AGENTS.md routes a fresh session to factual architecture, setup,
  validation, recovery, task scope, progress and completion requirements.
- A standard-library CLI provides preflight, resume, checks, checkpoint and drift;
  it neither installs an agent runtime nor publishes/deploys or contacts Jira.
- A validated ledger records owner, prerequisites, acceptance, scope provenance,
  next action and evidence. Reject invalid dependencies, cycles and concurrent tasks.
- Required command failures, missing/stale/tampered evidence and builder-authored
  review cannot establish passing. Independent review remains outstanding until real.
- Positive and negative lifecycle fixtures prove failure, stale-state recovery,
  checkpoint/resume and safe path handling; existing package/docs checks still run.
- Source adoption covers the 14 course topics and identifies relevant projects,
  templates, reference implementation and deliberate deferrals without performance claims.
- Runtime, dependencies, existing test sources and publish.yml remain unchanged.
  Deliver a focused branch and draft PR; do not merge, publish or deploy.
